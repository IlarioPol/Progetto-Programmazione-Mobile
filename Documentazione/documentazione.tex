\section{Descrizione del sistema, del funzionamento e dei requisiti}
Il sistema è un'applicazione mobile Android per la gestione di attività personali e/o di team. Consente all'utente di creare, modificare, eliminare e organizzare attività (task), assegnare priorità e scadenze, e sincronizzare i dati con un servizio remoto.

Funzionamento principale:
\begin{itemize}[noitemsep]
    \item Registrazione e autenticazione utenti tramite credenziali; supporto token per sessioni persistenti.
    \item Interfaccia utente che mostra liste di attività filtrabili e ordinabili.
    \item Creazione e modifica task con titolo, descrizione, data di scadenza, priorità e stato.
    \item Sincronizzazione bidirezionale con backend (REST API): invio modifiche locali e ricezione aggiornamenti remoti.
    \item Supporto offline: le modifiche vengono salvate localmente (database locale) e sincronizzate quando la connettività è disponibile.
    \item Notifiche locali/push per ricordare scadenze importanti.
\end{itemize}

Requisiti funzionali essenziali:
\begin{itemize}[noitemsep]
    \item RF1: Autenticazione utente (login/logout, registrazione).
    \item RF2: CRUD per le attività.
    \item RF3: Filtri e ordinamenti per visualizzare attività.
    \item RF4: Sincronizzazione con servizio remoto e risoluzione conflitti basica.
    \item RF5: Notifiche per scadenze.
\end{itemize}

Requisiti non funzionali:
\begin{itemize}[noitemsep]
    \item RNF1: Compatibilità con Android 8.0 (API 26) e successive.
    \item RNF2: Risposta UI entro 200 ms per operazioni comuni.
    \item RNF3: Sicurezza: comunicazione cifrata (HTTPS), memorizzazione sicura dei token.
    \item RNF4: Scalabilità backend per gestire più utenti concorrenti.
    \item RNF5: Accessibilità e supporto localizzazione (i18n).
\end{itemize}

Vincoli:
\begin{itemize}[noitemsep]
    \item Uso di una REST API standard per sincronizzazione.
    \item Persistenza locale tramite SQLite/Room.
    \item Autenticazione basata su token (es. JWT) o OAuth2.
\end{itemize}

\section{Glossario dei termini}
\begin{description}[noitemsep]
    \item[Utente] Persona che utilizza l'app.
    \item[Task / Attività] Elemento gestibile dall'utente con titolo, descrizione, stato e scadenza.
    \item[Autenticazione] Processo di verifica dell'identità dell'utente (login).
    \item[Token (es. JWT)] Credenziale temporanea usata per autorizzare richieste al backend.
    \item[API REST] Interfaccia HTTP per comunicazione client-server.
    \item[Database locale] Archivio dati sul dispositivo (es. SQLite/Room) per supporto offline.
    \item[Sincronizzazione] Processo di allineamento dati tra dispositivo e server.
    \item[Push notification] Messaggio inviato dal server al dispositivo per avvisi in background.
    \item[Endpoint] URL specifico dell'API che espone una funzionalità/back-end.
    \item[CRUD] Operazioni Create, Read, Update, Delete.
    \item[Backend] Server che gestisce logica, storage e API esposte all'app.
    \item[Conflitto di sincronizzazione] Situazione in cui la stessa risorsa è cambiata contemporaneamente in locale e sul server.
\end{description}
